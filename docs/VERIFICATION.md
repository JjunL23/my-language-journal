# V1.0 验证记录

验证日期：2026-10-26。

## 已通过

- TypeScript 严格检查与 Vite 正式构建。
- 79 项数据层单元测试：字段规则、Unicode 三语搜索、备份版本与格式、重复 ID、事务回滚、容量边界、跨窗口修改冲突、Replace 原子性、迁移保留资料和失败回滚。
- 14 项 Chromium 浏览器测试：单语新增、补充三语、保留 ID 的编辑、草稿确认、收藏与类型筛选、删除确认、JSON 下载与完整恢复、重复内容提示。
- 浏览器 Back 触发未保存提醒；继续编辑保留输入，放弃和保存后恢复正常导航，后续编辑不会留下失效的历史保护。
- Replace 的两阶段确认、取消后资料不变、空备份保护，以及另一窗口在预览后修改记录时拒绝覆盖并重新预览。重复导入不产生重复 ID。
- 两个真实生产构建在同一网址切换：新版等待、另一窗口激活、编辑草稿不强制刷新、主动更新后 ID／三语／备注／收藏／时间全部保留，旧资源缓存清理，离线关闭页面再打开新版。
- 浏览器断网后 reload，以及关闭页面再重新打开；离线新增、修改、搜索、收藏、删除和导出。
- 320、390、768、1280 像素宽度的横向溢出检查，手机尺寸表单操作；手机页面按钮至少 44px，390 × 420 的短视口中 Notes 和保存按钮可见。这只是键盘占用空间的模拟，不等同于 iOS 软键盘测试。
- 六个核心手机界面的 axe WCAG A/AA 自动检查未发现违规项；另做桌面与手机截图检查。这不等同于完整人工无障碍认证。
- GitHub Pages 子路径构建：24 个缓存资源均存在，包含本地字体与图标。
- 安装依赖的 npm audit 未发现已知漏洞。
- 核心操作与更新场景未出现浏览器关键错误，未发现跨域资源请求或记录上传请求。
- GitHub Pages 首次部署成功；发布网站的 HTTPS 页面已实际打开检查。

测试使用独立浏览器资料区及合成记录，没有写入用户的日常资料。
