## 安装与布局

- [ ] Safari 打开正式 HTTPS 地址，确认页面加载完毕。
- [ ] 分享 → Add to Home Screen，打开 Open as Web App，加入主屏幕。
- [ ] 从主屏幕启动，确认图标清晰、独立窗口正常、页面没有 Safari 地址栏。
- [ ] 检查顶部刘海／Dynamic Island、底部 Home 指示条区域，按钮不被遮挡。
- [ ] 横竖屏切换后，三语文字、操作按钮和导航不重叠。
- [ ] 输入三种语言，软键盘弹出后当前输入框与保存按钮都可访问；切换 Notes、输入法候选栏和横竖屏后仍正常，关闭键盘后布局恢复。
- [ ] 使用大字号或系统文字缩放，长词块与多行中文仍完整可访问。

## 记录与保护

- [ ] 新增仅英文、仅中文、仅马来文各一条记录，均可保存。
- [ ] 全空或只有空格时不能保存，并提示至少填写一种语言。
- [ ] 分别新增 Word 和 Chunk，筛选正确。
- [ ] 编辑同一条记录后总数量不增加，内容及更新时间改变。
- [ ] 连续快速点保存，不生成重复记录。
- [ ] 输入与已有记录相同的内容时出现提示，但仍能按自己的意愿保存另一条独立记录。
- [ ] 修改后尝试退出编辑，确认出现未保存提醒；取消退出保留输入。
- [ ] 在 Safari 使用返回手势／返回按钮离开未保存编辑时，提醒有效；选择继续编辑保留文字。
- [ ] 删除前出现确认；取消后原记录保留；确认后只删除选中记录。
- [ ] 收藏与取消收藏能立即反映；取消收藏不会删除 Library 原记录。
- [ ] 英文大小写、中文和马来文搜索均找到正确内容；清空搜索恢复列表。
- [ ] 很长的文字、换行、标点和 HTML 样式字符串作为普通文字显示。

## 飞行模式与保存

- [ ] 在主屏幕 App 中联网等候离线准备完成。
- [ ] 开启飞行模式，并关闭可能仍开启的 Wi-Fi。
- [ ] 完全关闭 App，再从主屏幕启动，仍显示界面、字体、图标和记录。
- [ ] 离线新增、修改、删除、搜索、收藏，所有操作正常。
- [ ] 再次完全关闭并重启，离线修改仍存在。
- [ ] 恢复网络后，离线资料不丢失、不重复。

## JSON 备份、合并与替换

- [ ] 导出当前全部记录，实际把 JSON 保存在「文件」App 并核对文件可打开。
- [ ] 再次导入同一文件，预览显示没有新增；确认后不产生重复记录。
- [ ] 导入包含新 ID 的测试备份，预览正确显示新增数量；取消后资料不改变。
- [ ] 导入包含相同 ID、不同内容的备份，预览正确显示更新数量；确认后只更新这些 ID。
- [ ] 备份未包含的现有记录仍保留。
- [ ] 导入默认选择 Merge；切换到 Replace 后清楚显示移除数量和最终记录数。
- [ ] Replace 预览确认后，仍须在第二个窗口明确确认；取消任一阶段都保留原资料。
- [ ] 在可安全测试的资料环境中确认 Replace 后，结果与备份逐项一致，原来不在备份中的记录已移除。
- [ ] 空备份 Replace 也须二次确认；取消后原资料保留。
- [ ] 预览之后另一窗口改变资料时，Replace 被拦截并要求重新确认。
- [ ] 无效 JSON、错误版本、重复 ID、错误字段和超大文件被拒绝，现有资料无变化。
- [ ] 在另一个可安全测试的空资料环境恢复备份，逐项核对三语、备注、类型、收藏和日期。
- [ ] 从 Safari 导出、再从已安装 App 导入，明确核对两个环境的资料，避免假定共享。

## 更新与数据安全

- [ ] 已保存真实资料前先完成上述备份恢复测试。
- [ ] 新版发布后显示更新提示；编辑输入中不会自动刷新。
- [ ] 保存输入再更新，新版打开后 IndexedDB 记录和收藏状态保留。
- [ ] 另一窗口先更新时，本窗口的未保存输入保留；保存后仍能正常切换到新版。
- [ ] Settings 中持久化请求被允许或拒绝时，反馈准确，普通操作仍可使用。
- [ ] 清楚知道清除网站资料、储存管理或移除 App 可能丢失数据，并有 App 外的备份。
