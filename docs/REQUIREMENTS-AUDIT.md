# 补充要求核对

核对日期：2026-10-26。沿用原有 V1.0 项目和界面，不重新实现已有功能。

| 要求 | 检查结论与处理 |
| --- | --- |
| IndexedDB 保存、重新打开保留记录 | 原有实现已满足；继续使用同一数据库名称与 entries store。 |
| 数据库版本与 Migration | 原有版本为 1；补上按版本顺序执行的迁移模块和回滚测试。没有数据结构变更，所以不人为提高版本。 |
| JSON 包含全部字段、Schema Version | 原有实现已满足；备份 `version: 1` 即数据结构版本，继续兼容原备份。 |
| Merge、验证、预览、冲突保护 | 原有实现已满足；保留按 ID 合并、重复 ID 拒绝和同事务快照检查。 |
| Replace 二次确认 | 原先缺少。补上独立模式、删除与最终数量预览、第二次明确确认，以及同事务验证、清除和写入。 |
| 本机保存、无服务器上传 | 原有实现已满足；业务代码没有网络上传；增加运行时网络检查。 |
| Persistent Storage | 原有实现已满足；保留请求结果反馈及不能代替备份的说明。 |
| Manifest、图标、离线、安装 | 原有实现已满足；维持静态 PWA，不使用在线字体或 CDN。 |
| Service Worker 更新 | 实际双版本测试发现跨窗口更新后按钮可能无反应，已针对性修复。增加草稿、数据、缓存与离线重开验证。 |
| Safe Area、触控目标、软键盘 | 沿用响应式设计，补齐 44px 目标和编辑器 Visual Viewport 适配；实际键盘与主屏幕仍需 iPhone 验收。 |
| 至少一种语言、可选 Notes、三语搜索 | 原有实现已满足。 |
| 相同内容提示但允许保存 | 原先缺少。补上非阻断提示；排除当前正在编辑的记录；新增仍生成独立 ID。 |
| 删除确认、未保存提醒、收藏语义 | 原有删除确认、编辑器关闭提醒和收藏语义已满足；补上浏览器 Back 的草稿保护。 |
| Empty State、错误与保存反馈 | 原有实现已满足；新流程沿用相同反馈方式。 |
| UI、数据、业务逻辑分层 | 数据层已有独立模块，但 App 文件过大；按页面、对话框和业务控制流程提取，不更换框架或设计体系。 |
| 无新增未确认功能 | 没有添加 Flashcards、翻译、同步、Tags、账户、后端或统计。 |

测试结果见 [VERIFICATION.md](VERIFICATION.md)。实机项目见 [IPHONE-CHECKLIST.md](IPHONE-CHECKLIST.md)。浏览器断网模拟不等同于真实 iPhone 飞行模式验收。
